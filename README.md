# Hey, I’m Austin!

I’m a Computer Science and Applied Mathematics student at Colby College, building software, AI, and systems projects that connect research, infrastructure, and real-world products.

Right now, I’m working across machine learning, full-stack engineering, and distributed systems — from QSAR models for drug discovery to infrastructure monitoring tools and startup products used by local businesses.

I care about building things that are useful, scalable, and technically sharp. A lot of my work sits at the intersection of software engineering, AI/ML, data, and systems design.

Currently:
- Machine Learning Intern at Morgan State CEAMLS / Summer AI Research Institute
- Co-founder of myLokala, a local coupon marketplace
- Building PulseGrid, a distributed infrastructure monitoring platform
- Practicing DSA, system design, and C++ for SWE / quant dev roles

## Featured Projects

### PulseGrid — Distributed Infrastructure Monitoring
A monitoring platform for distributed services with lightweight agents, FastAPI ingestion, PostgreSQL persistence, Redis caching, Kafka streaming, and a real-time Next.js dashboard.

### myLokala — Local Coupon Marketplace
A full-stack coupon marketplace for local businesses in Waterville, built with Next.js, Supabase, authentication, row-level security, redemption tracking, and merchant dashboards.

### QSAR Drug Discovery Pipeline
A machine learning workflow for screening Alzheimer’s-related compounds using molecular descriptors, XGBoost, Gradient Boosting, classification metrics, and compound ranking.
