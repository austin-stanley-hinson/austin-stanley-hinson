## Featured Projects

### PulseGrid — Distributed Infrastructure Monitoring
A monitoring platform for distributed services with lightweight agents, FastAPI ingestion, PostgreSQL persistence, Redis caching, Kafka streaming, and a real-time Next.js dashboard.

### myLokala — Local Coupon Marketplace
A full-stack coupon marketplace for local businesses in Waterville, built with Next.js, Supabase, authentication, row-level security, redemption tracking, and merchant dashboards.

### QSAR Drug Discovery Pipeline
A machine learning workflow for screening Alzheimer’s-related compounds using molecular descriptors, XGBoost, Gradient Boosting, classification metrics, and compound ranking.
